# Pachamama ERP

## Descripción del Proyecto

Pachamama ERP es una solución integral de software empresarial para el sector agroindustrial. El sistema centraliza la gestión operativa de plantas de empaque y procesamiento agrícola, permitiendo el registro y trazabilidad completa del producto desde la recepción de materia prima hasta su despacho final.

## Módulos y Funcionalidades

- Módulo de Recepción: Registro de peso en balanza, ingreso de materia prima y asignación de lotes.
- Módulo de Calibrado y Calidad: Clasificación por calibres, medición de parámetros de calidad y control de descarte.
- Módulo de Tareo y Cuadrillas: Control de asistencia de personal, rendimiento por turno y asignación de tareas.
- Módulo de Costeo Operativo: Consolidación de costos directos e indirectos por lote procesado.
- Módulo de Trazabilidad: Seguimiento integral de la cadena de procesamiento agrícola.

## Estructura y Tecnologías

- Frontend: HTML5, CSS3, JavaScript (ES6+ Single Page Application)
- Base de Datos: Firebase Firestore (NoSQL en tiempo real)
- Infraestructura Cloud: Google Cloud Platform (GCP)
- Reglas de Seguridad: Firestore Security Rules
